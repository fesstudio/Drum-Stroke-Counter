# 🥁 Drum Stroke Counter - The Ultimate Speed & BPM Tracker

[![Android](https://img.shields.io/badge/Platform-Android-brightgreen.svg)](https://developer.android.com/)
[![Kotlin](https://img.shields.io/badge/Language-Kotlin-blue.svg)](https://kotlinlang.org/)
[![License](https://img.shields.io/badge/License-MIT-orange.svg)](LICENSE)

**Drum Stroke Counter** is a high-performance Android application designed specifically for drummers to measure their speed, stroke accuracy, and consistency. Using advanced audio analysis, this app counts every single hit in real-time.

---

## 🚀 Key Features

*   **Real-Time Stroke Detection:** High-accuracy audio engine to detect drum hits even at high speeds.
*   **Strokes Per Second (SPS):** Track your peak and average speed during practice sessions.
*   **BPM Monitoring:** Automatically calculate beats per minute based on your drumming patterns.
*   **Session History:** Detailed logs of your past practice sessions with date, duration, and speed statistics.
*   **Calibration System:** Intelligent noise floor detection to ensure accuracy in any environment (rehearsal room, studio, or stage).
*   **Modern UI:** Clean, dark-themed interface built with **Jetpack Compose** for the best user experience.

---

## 🛠️ Built With (Tech Stack)

*   **Language:** [Kotlin](https://kotlinlang.org/) - 100% Type-safe and modern.
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) - Declarative UI for Android.
*   **Architecture:** Clean Architecture with MVVM pattern.
*   **Dependency Injection:** [Hilt](https://developer.android.com/training/dependency-injection/hilt-android).
*   **Database:** [Room Persistence Library](https://developer.android.com/training/data-storage/room) for session history.
*   **Audio Engine:** Low-latency `AudioRecord` API with custom signal processing.

## 🔧 Installation & Usage

1.  Clone the repository:
    ```bash
    git clone https://github.com/fesstudio/Drum-Stroke-Counter.git
    ```
2.  Open in **Android Studio** (Electric Eel or newer).
3.  Build and run on your physical Android device (Recommended for audio latency).
4.  Go to **Settings/Calibration** to set your threshold before starting.
